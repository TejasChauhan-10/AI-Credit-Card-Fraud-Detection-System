# Day 7 - Streamlit Dashboard & End-to-End Integration

## Objective

* Build a user-friendly frontend interface.
* Connect the dashboard with the FastAPI backend.
* Display fraud predictions and risk intelligence results in real time.

## Streamlit Setup

Installed:

* Streamlit
* Requests

Created:

frontend/dashboard.py

## Dashboard Features

### Transaction Input Form

Users can enter:

* Transaction Type
* Amount
* Old Balance Origin
* New Balance Origin
* Old Balance Destination
* New Balance Destination

### API Integration

Connected Streamlit dashboard to:

http://127.0.0.1:8000/predict

using HTTP POST requests.

## Fraud Analysis Workflow

Transaction Input
↓
Streamlit Dashboard
↓
FastAPI API
↓
Random Forest Model
↓
Risk Scoring Engine
↓
Fraud Intelligence Report

## Dashboard Outputs

### Prediction

Fraud / Legitimate

### Fraud Probability

Percentage confidence generated by the Random Forest model.

### Risk Score

Range: 0 - 100

### Risk Level

* LOW
* MEDIUM
* HIGH

### Investigation Reasons

Examples:

* Large transaction amount
* High balance utilization
* High-risk transaction type
