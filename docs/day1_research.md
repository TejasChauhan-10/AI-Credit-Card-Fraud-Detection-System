# Day 1 Research

## Dataset
PaySim Financial Transaction Dataset

## Statistics
- Total Transactions: 6,362,620
- Fraud Cases: 8,213
- Fraud Percentage: 0.129%

## Key Findings
- Dataset is highly imbalanced.
- Fraud occurs almost entirely in CASH_OUT and TRANSFER transactions.
- No missing values found (verify with analysis).
- Accuracy is not a reliable metric for this problem.
